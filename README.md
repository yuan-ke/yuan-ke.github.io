# yuan-ke.github.io

Personal academic website of Yuan Ke (Department of Statistics, University of Georgia), served at https://yuan-ke.github.io via GitHub Pages.

Built with Jekyll on the [AcademicPages](https://github.com/academicpages/academicpages.github.io) template (a fork of Minimal Mistakes, MIT License — see `LICENSE`).

## Where things live

| Page | File |
|---|---|
| Home / bio | `_pages/about.md` |
| Research | `_pages/research_YK.md` |
| Publications | `_pages/publist_YK_Full.md` |
| Teaching | `_pages/teaching_YK.md` |
| Students | `_pages/Students_YK.md` |
| Top menu | `_data/navigation.yml` |
| Sidebar, site settings | `_config.yml` |
| Paper PDFs | `files/` |

## Run locally

```
bundle install
bundle exec jekyll serve
```
Then open http://localhost:4000.
